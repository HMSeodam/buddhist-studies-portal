# 불교학논문 통합검색

**[앱 바로실행](https://hmseodam.github.io/buddhist-studies-portal)**

불교계 학술지 30종의 논문을 통합 검색하는 무료 학술 서비스입니다.

---

## 핵심 기능

- **통합 검색**: 논문명 · 저자명 · 키워드 · 초록을 전체 학술지에서 한 번에 검색
- **학술 검색식**
  - `원효 기신론`: 띄어 쓴 단어가 모두 들어간 논문 (AND)
  - `"대승 기신론"`: 구절 검색 (띄어쓰기 차이는 무시)
  - `화엄 | 華嚴`: 둘 중 하나 (OR)
  - `선 -간화선`: 제외 (NOT)
  - `저자:김영미`, `제목:`, `키워드:`, `초록:`, `학술지:`: 필드 지정 (필터바의 '검색 범위'로도 선택 가능)
- **한자·한글 자동 확장**: `기신론` ↔ `起信論`, `원효` ↔ `元曉`, `佛` ↔ `仏` 같은 불교 용어·인명·이체자를 함께 찾습니다
- **오타 보정**: 정확히 일치하는 결과가 없으면 제목이 비슷한 논문을 제안합니다
- **검색어 문맥 보기**: 초록 중 검색어가 나온 부분을 강조해서 보여 줍니다
- **필터**: 카테고리 · 학술지 · 국가 · 연도(최근 3/5/10년, 연대별) · 권호 · 정렬
  - 사이드바에 학술지별 결과 수가 표시됩니다
  - 적용 중인 필터는 결과 위에 칩으로 표시되고, × 로 하나씩 해제할 수 있습니다
- **공지사항**: 우측 상단 🔔 버튼에서 "2026-09-24 동아시아불교문화 76호 20편 업데이트" 같은 소식을 봅니다. 항목을 누르면 그 호로 바로 이동합니다
- **링크 공유**: 검색 조건과 열어 본 논문이 주소에 저장되어, 링크를 복사해 공유하거나 새로고침해도 그대로 유지됩니다
- **인용 · 내보내기**: 국문 인용 형식 복사, BibTeX, RIS(Zotero·EndNote), 검색 결과 CSV(엑셀)
- **원문 링크**: RISS · KCI · DOI · 학술지 홈페이지 · Google Scholar
- **기기 지원**: PC · 태블릿 · 스마트폰 (가로/세로)

## 데이터 구조 (2026-09 개편)

```
data/riss/riss_<학술지>.json   RISS 수집기가 쌓는 원본
data/kci/kci_<학술지>.json     KCI 수집기가 쌓는 원본 (KCI 논문번호로 갱신)
data/kci/_candidates.json      이름이 다른 KCI 학술지 후보 (제목 대조로 검증)
        │
        ▼  collector/build_output.py  (매 실행마다 처음부터 다시 대조)
output/riss_<학술지>.json      앱이 읽는 파일
output/updates.json            공지
```

- 수집기는 **자기 원본에만** 씁니다. RISS·KCI를 합치는 일은 빌드 단계 한 곳에서만 하므로, 어느 쪽이 먼저 오든 결과가 같습니다.
- **같은 논문 판정** (`collector/paper_match.py`): 같은 학술지에서 권·호 숫자가 같고 연도 차이가 ±1인 호를 먼저 찾습니다. 그 안에서 한자를 한글 독음으로 바꾼 제목의 유사도와 시작 쪽수를 함께 보고 1:1로 짝짓습니다.
  - 弘覺禪師碑文 ↔ 홍각선사비문
  - `<특집논문1> …: 제목` ↔ `제목`
  - RISS "46권" ↔ KCI "46호"
- **권·호 표기**: KCI에만 있는 논문도 같은 호의 RISS 표기(권/호·연도)에 맞춥니다.
- **학술지 대응 검증**: KCI 레코드와 RISS 제목이 맞는 비율을 발행기관별로 계산합니다. 확인되지 않은 KCI 단독 논문은 보류합니다. 이름이 다른 후보(예: 禪文化硏究)는 우리 학술지와 제목이 60% 이상 맞으면 자동으로 연결합니다.
- **공지**: 어느 출처의 번호로도 처음 보는 논문만 새 논문으로 칩니다. 올해·작년 발행분만 공지합니다.
- **KCI 원문**: KCI 논문번호가 있는 논문은 KCI 개별 논문 페이지로 바로 연결합니다(PC·모바일 주소 자동 선택). 번호가 없는 논문(KCI 미수록 등)에는 'KCI 홈페이지' 버튼이 나옵니다.
- **KCI 논문번호 연결** (`collector/kci_link.py`, KCI Open API 인증키 필요): RISS로 받은 논문마다 KCI 번호를 찾아 붙입니다.
  1. 학술지·연도별로 한 해치 논문을 받아 호 단위로 대조합니다.
  2. 남은 논문은 제목(한글·한자 표기 모두)으로 하나씩 검색합니다.
  3. 같은 학술지·같은 호·제목 유사도·쪽수를 모두 확인한 것만 연결합니다.
  - KCI에 해당 연도가 아예 없는 옛 호(KCI 수록 이전)는 묻지 않고 넘어가며, 90일 뒤 다시 확인합니다.
  - 인증키가 없어도 **KCI 전체 수확**으로 모든 논문의 번호를 채울 수 있습니다.
    - Actions → Run workflow에서 target `kci`, kci_from `2013-03-21`(KCI 기록 시작일)로 실행합니다.
    - 끝날 때까지 같은 값으로 여러 번 실행하면, 매번 멈춘 자리(쪽 위치)부터 이어받습니다.
  - KCI 웹 화면(학술지 목록 페이지)을 긁어 오는 방식은 쓰지 않습니다. KCI가 robots.txt로 자동 수집을 막아 두었고, 공식 통로(OAI·Open API)가 따로 있기 때문입니다.

## 자동 업데이트

`.github/workflows/update.yml`이 요일별로 학술지를 나눠 매일 수집합니다.

| 단계 | 내용 |
|---|---|
| KCI (선택) | 공식 OAI-PMH로 신규 논문 수집. 인증키 없이 사용 가능 |
| RISS | 요일별 5개 학술지 (일요일은 전체 점검) |
| IBK | 매월 1일, J-Stage |
| 출력 빌드 | RISS·KCI 원본을 대조해 output 과 공지를 새로 만듦 |
| 커밋 | 앞 단계가 실패하거나 시간을 초과해도 수집된 만큼은 반드시 저장 |

### RISS 차단 대응 (2026-09)

- 차단 문구, 경고창, 팝업, 빈 응답, 시간 초과를 감지하면 3 → 7 → 15 → 25분 동안 쉬고 브라우저 세션을 새로 엽니다
- 서버가 느려지면 모든 대기 시간을 자동으로 늘립니다 (최대 4배)
- 상세 페이지의 제목·학술지명·연도·호수를 목록과 대조합니다. 어긋나는 **허위 응답**은 저장하지 않고, 다음 실행 때 다시 수집합니다
- 시간 예산(기본 290분) 안에서 스스로 멈춘 뒤 저장합니다. 끝내지 못한 학술지는 `collector/state/riss_pending.json`에 남아 다음 실행이 이어받습니다
- 차단으로 미완료되면 같은 실행 안에서 20분, 40분을 쉬었다가 남은 학술지만 다시 시도합니다

### KCI 연동 켜기

1. 저장소 **Settings → Secrets and variables → Actions → Variables**에 `KCI_ENABLED` = `true`를 추가합니다
2. (선택) KCI Open API 키를 발급받아 **Secrets**에 `KCI_API_KEY`로 넣으면 키워드까지 받아옵니다
3. 첫 실행 전에 **Actions → Run workflow**에서 target을 `kci`로 두고 한 번 실행한 뒤, 로그에서 학술지명이 맞게 연결되는지 확인하세요
   - 로컬에서는 `python kci_oai_updater.py --discover --dry-run`으로 이름이 다른 학술지를 찾을 수 있습니다

### 공지 직접 쓰기

`output/updates.json`의 `notices`에 한 줄을 추가하면 됩니다.

```json
{"date": "2026-10-01", "text": "10월 정기 점검 안내", "pinned": true}
```

`updates`는 수집기가 자동으로 기록합니다.
