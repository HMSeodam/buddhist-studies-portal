# 불교학논문 통합검색

**[앱 바로실행](https://hmseodam.github.io/buddhist-studies-portal)**

불교계 학술지 26종의 논문을 통합 검색하는 무료 학술 서비스입니다.

---

## 핵심 기능

- **통합 검색** — 논문명 · 저자명 · 키워드로 전체 학술지 동시 검색
- **학술지별 탐색** — 26개 학술지를 학술지명 / 발행기관 / 최신호 순으로 정렬
- **논문 상세 정보** — 저자 · 초록 · 키워드 · 발행 정보 제공
- **원문 링크** — RISS · KCI · 학술지 홈페이지 바로가기
- **모바일 최적화** — PC · 스마트폰 모두 지원
- **자동 업데이트** — 매주 신규 논문 자동 수집

## 수록 학술지

불교학 · 불교미술사학 · 불교사학 분야 KCI 등재지 26종
